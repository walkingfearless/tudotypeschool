Português

Sobre o Docente

Apresentação de João Miranda — percurso profissional em branding e type design (Pentagram, Wolff Olins, Automattic), projectos de destaque (Cohere, Decathlon Sans), fundação da tudotype e actividade de ensino.

Configurar o GitHub

Guia passo a passo para criar uma conta no GitHub, instalar o GitHub Desktop, clonar o repositório do workshop e entregar o primeiro projecto. Inclui as regras de ficheiros do repositório e dicas para usar commits de forma eficaz.

Fontra — Primeiros Passos

Guia geral do editor Fontra. Cobre a instalação do Fontra Pak em macOS, Windows e Linux, como abrir uma fonte, formatos de ficheiro suportados (.fontra, .ufo, .glyphs, .ttf…), visão geral da interface, ferramentas de desenho e uma referência rápida de atalhos.

Fontra Pak — Guia de Aula

Guia específico para a aula. Explica como abrir e explorar o projecto ZalandoSans (fonte variável com eixos de Peso e Largura), iniciar um novo projecto do zero (configuração de Font Info, métricas, eixos variáveis, ordem de desenho dos glifos) e como exportar para UFO+DesignSpace, TTF/OTF variável e instâncias estáticas.

Fontra — Campos de Informação da Fonte

Referência rápida para os metadados do painel Font Info do Fontra: nome da família, copyright, designer, fabricante, URL do vendedor, versão, UPM, e os campos de métricas verticais (ascendente, descendente, altura-x, altura de caixa alta).

Desenho Tipográfico II — Notas de Aula

Notas de aula completas sobre o processo de desenho tipográfico. Temas: forma e contraforma, caracteres de referência (H, O, n, o, y), análise da caixa alta e caixa baixa, compensações ópticas (eixo de stress, contraste de traço, overshoot, intersecções), métricas verticais (ascendente, descendente, altura-x), espaçamento e kerning, processo analógico de desenho e sistema de linhas de referência. Inclui ilustrações tipográficas.

Recursos

Lista curada de referências, ferramentas e leituras de apoio ao curso — organizada por tema. Inclui o artigo de Jonathan Hoefler sobre os dez princípios do type design, os tutoriais do Glyphs, a Ohno Type School, o directório de fontes variáveis v-fonts.com, The Elements of Typographic Style Applied to the Web, e uma colecção de recursos gerais. Será actualizada ao longo do semestre.

English

About the Instructor

Profile of João Miranda — professional background in branding and type design (Pentagram, Wolff Olins, Automattic), key projects (Cohere, Decathlon Sans), founding of tudotype, and teaching activity.

Setting Up GitHub

Step-by-step guide to creating a GitHub account, installing GitHub Desktop, cloning the workshop repository, and submitting your first project. Includes the repository file rules and tips for committing effectively.

Fontra — Getting Started

General guide to the Fontra editor. Covers installing Fontra Pak on macOS, Windows and Linux, opening a font, supported file formats (.fontra, .ufo, .glyphs, .ttf…), interface overview, drawing tools, and a quick-reference cheatsheet of shortcuts.

Fontra Pak — Class Guide

Class-specific guide. Explains how to open and explore the ZalandoSans project (variable font with Weight and Width axes), start a new project from scratch (Font Info setup, metrics, variable axes, glyph drawing order), and how to export to UFO+DesignSpace, variable TTF/OTF, and static instances.

Fontra — Font Info Fields

Quick reference for the Font Info panel metadata in Fontra: family name, copyright, designer, manufacturer, vendor URL, version, UPM, and the vertical metrics fields (ascender, descender, x-height, cap height).

Typographic Drawing II — Class Notes

Full class notes on the typographic drawing process. Topics: form and counterform, reference characters (H, O, n, o, y), uppercase and lowercase analysis, optical compensations (stress axis, stroke contrast, overshoot, intersections), vertical metrics (ascender, descender, x-height), spacing and kerning, the analog drawing process, and the baseline reference system. Includes typographic illustrations.

Resources

A curated list of references, tools, and reading material — organised by topic. Includes Jonathan Hoefler’s ten principles for first-time type designers, Glyphs tutorials, the Ohno Type School, the v-fonts.com variable font directory, The Elements of Typographic Style Applied to the Web, and a community-curated resource hub. Updated throughout the semester.
