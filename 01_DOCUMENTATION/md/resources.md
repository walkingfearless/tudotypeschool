## Getting Started

### [Getting Started with Typeface Design — Jonathan Hoefler](https://jonathanhoefler.com/articles/getting-started-with-typeface-design)
Ten principles for first-time type designers, written by one of the most respected names in the field. Hoefler distils decades of professional experience into concrete, actionable advice: know your brief before you draw; prioritise fit over flawless drawings; look more and draw less; resist over-ambition with the character set; and treat digitising an existing typeface as a foundational learning exercise. A must-read before starting your project.

## Learning Type Design

### [Glyphs — Learn](https://glyphsapp.com/learn)
An extensive library of tutorials produced by the Glyphs team covering type design and font production from the ground up. Articles range from beginner topics (drawing basics, sidebearings, spacing) to advanced production workflows (OpenType features, variable fonts, scripting with Python). Even if you are using Fontra rather than Glyphs, the design principles and production concepts translate directly.

### [Ohno Type School — Teaching Articles](https://ohnotype.co/blog/tagged/teaching)
A series of blog posts by James Edmondson at OH no Type Company, structured as a letter-by-letter type school. Each article analyses a specific character — A, C, E, O, S, and more — examining its construction, the decisions that define its quality, and common mistakes. Also includes articles on spacing, getting started, and a set of rules for teachers and students originally by Sister Corita Kent and John Cage. Practical, opinionated, and written in plain language.

### [Type Design Resources](https://typedesignresources.com)
A large, community-curated and open-source collection of type design resources maintained on GitHub. Covers everything from beginner courses and glyph construction guides, to variable font tools, proofing utilities, font engineering references, typography terminology, and diacritics resources. A reliable starting point when looking for anything specific in the field.

## Typography on the Web

### [The Elements of Typographic Style Applied to the Web](https://webtypography.net)
An authoritative web-based reference by Richard Rutter that translates Robert Bringhurst's classic book *The Elements of Typographic Style* into practical CSS and HTML guidance. Walks through Bringhurst's working principles chapter by chapter, showing how to implement each using modern web technology. An essential companion for understanding how timeless typographic rules apply to screen contexts. Rutter later expanded this into the book *Web Typography* (2017).

---

## Variable Fonts

### [v-fonts.com](https://v-fonts.com)
An interactive showcase and directory of variable fonts. Each entry includes live sliders for every axis the font exposes — weight, width, optical size, slant, and custom axes — letting you explore the full design space directly in the browser. A useful reference for understanding what variable fonts are capable of in practice, and for finding specimens that demonstrate specific axis behaviours.
