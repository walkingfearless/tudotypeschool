UAlg Type Design Workshop — Project Brief

Format: 5-hour workshop + self-directed continuation Tool: Fontra (browser-based, no installation needed) Output: A working font file (.otf) for use in a poster design

The brief

Design a display typeface — or a distinctive set of glyphs — that you can use as the headline or key typographic element of a poster.

You don’t need to design a full alphabet. You need to design enough — enough to set a word, a name, a phrase, or a title that means something to you and that can carry a poster visually.

Two paths

Path A — Modify

Start from the provided font file and reshape it into something that feels like yours. Change the weight, distort the proportions, add texture, cut into the forms, exaggerate features. The source is a starting point, not a constraint.

Path B — From scratch

Define a short word or phrase (your name, a concept, a title) and design only the glyphs you need to set it. Fewer letters, more attention to each one.

Both paths are equally valid. Choose the one that matches how you want to work today.

What “done” looks like

By the end, you should have:

  • [ ] At least enough glyphs to set a meaningful word or short phrase
  • [ ] A font file you can install and use in Illustrator, InDesign, or Figma
  • [ ] A clear sense of what your type is for — what poster it belongs on

You do not need: a full alphabet, perfect spacing, or a complete character set.

Some prompts to get you started

If you’re not sure where to begin, pick one of these as a starting point:

  • A place — somewhere you’re from, somewhere you want to go
  • A sound — a genre of music, a noise, an atmosphere
  • A feeling — tension, comfort, chaos, slowness
  • A material — wood, concrete, neon, rust, fabric
  • Something broken or unfinished — and make that the point

You don’t have to use a prompt. But having a direction helps you make decisions.

Glyph groups — shared DNA

Letters are not designed in isolation. Most glyphs in a typeface share structural elements with a handful of others — the same curve, the same stroke weight, the same terminal. Understanding these families means you can make a large number of decisions with a small number of moves.

Letter families (uppercase)

Letters within each group share underlying shapes and construction logic. Decisions you make in one letter should inform — or be directly reused in — the others:

Group Letters Shared logic
Round O C G Q Same oval, same curve weight
Vertical + crossbar H L E F I T Uprights and horizontal strokes
Arch H O H O H O Repeated arch rhythm (test string)
Bowl B P R Shared upper/lower bowl construction
Diagonal (open) A V M N Diagonal strokes, apex/vertex
Diagonal (closed) V W Y X Shared diagonal angles
Diagonal + horizontal E Z V Horizontal meets diagonal
Leg R K The leg and arm off a stem
Curved base J U Curve returning to baseline
Spine S The unique one — but it echoes the round group’s weight

What this means in practice

Design one letter in a group well, and you already have the skeleton of the others. This is the core idea behind component-based design — building glyphs from shared, reusable parts. In Fontra, components let you place one glyph inside another: change the source, and every glyph that uses it updates automatically.

Even if you only need five letters for your poster, knowing which family they belong to helps you make them feel like they come from the same system.

Tips for the session

  • Spend the first part observing. Look at display type you love and try to describe why it works — weight, contrast, rhythm, detail.
  • Don’t try to draw everything at once. Start with one or two letters that define the character of the font (typically a round and a straight — like O and H).
  • Let the groups guide you. Once you’ve drawn one letter, use its shapes directly in its relatives before moving on.
  • Consistency comes from repetition, not perfection. Reuse shapes and decisions across glyphs.
  • Export early. Test your font in context as soon as you have a few glyphs. Seeing it in a layout tells you things the editor can’t.

Delivery

There is no formal submission for the workshop itself. After the session, continue refining at your own pace. When you’re ready, export your font (File → Export → OTF) and use it in a poster. The poster is yours to design — the brief ends at the font file.
