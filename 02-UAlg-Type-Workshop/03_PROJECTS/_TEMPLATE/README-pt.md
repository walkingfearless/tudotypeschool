---

## Regras de Ficheiros

- Mantém todos os ficheiros de trabalho em `sources/`
- Exporta as fontes compiladas para `exports/` — não para `sources/`
- Imagens de referência (JPG, PNG) são bem-vindas em `references/` — mas mantém cada ficheiro abaixo de 10 MB
- **Não** faças commit de ficheiros Adobe (`.ai`, `.psd`, `.indd`), vídeos ou arquivos ZIP
- Se um ficheiro tiver mais de 50 MB, fala com o docente antes de fazer commit
