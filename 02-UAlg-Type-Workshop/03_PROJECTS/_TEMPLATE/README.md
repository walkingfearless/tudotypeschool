---

## File Rules

- Keep all working files in `sources/`
- Export compiled fonts to `exports/` — not to `sources/`
- Reference images (JPGs, PNGs) are welcome in `references/` — but keep individual files under 10 MB
- Do **not** commit Adobe files (`.ai`, `.psd`, `.indd`), video, or ZIP archives
- If a file is larger than 50 MB, ask your instructor before committing it
