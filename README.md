# tudotypeschool

Repositório de recursos de ensino para workshops de design tipográfico, criado e mantido por **João Miranda** (Brand Designer na Automattic, fundador da [tudotype](https://tudotype.com)).

O repositório está organizado por workshop. Cada pasta de workshop contém os materiais específicos dessa edição — ficheiros de demonstração, projectos de alunos e guias de aula. A documentação de apoio, partilhada entre todos os workshops, está centralizada na pasta `01_DOCUMENTATION`.

## Estrutura

```
tudotypeschool/
├── 01_DOCUMENTATION/       ← Documentação de apoio — abre o index.html para começar
├── 02-UAlg-Type-Workshop/  ← Workshop de Desenho Tipográfico · Universidade do Algarve · 2026
└── ...                     ← Futuros workshops seguirão a mesma estrutura numerada
```

## Como começar (alunos)

1. Instala o GitHub Desktop — consulta o guia [Configurar o GitHub](01_DOCUMENTATION/docs/setting-up-github-pt.html)
2. Clona este repositório para o teu computador
3. Abre `01_DOCUMENTATION/index.html` no browser para acederes a todos os materiais de aula
4. Na pasta do teu workshop, copia a pasta `_TEMPLATE` em `03_PROJECTS/` e renomeia-a com o teu nome

O repositório é público para que possas experienciar a dinâmica colaborativa do GitHub e o controlo de versões — ferramentas fundamentais no desenvolvimento de fontes tipográficas.

# tudotypeschool

A teaching resource hub for type design workshops, created and maintained by **João Miranda** (Brand Designer at Automattic, founder of [tudotype](https://tudotype.com)).

The repository is organised by workshop. Each workshop folder contains its own materials — demo files, student projects, and class guides. Supporting documentation shared across all workshops is centralised in `01_DOCUMENTATION`.

## Structure

```
tudotypeschool/
├── 01_DOCUMENTATION/       ← Shared documentation — open index.html to get started
├── 02-UAlg-Type-Workshop/  ← Typographic Drawing Workshop · University of Algarve · 2026
└── ...                     ← Future workshops will follow the same numbered structure
```

## Getting started (students)

1. Install GitHub Desktop — see the [Setting Up GitHub](01_DOCUMENTATION/docs/setting-up-github.html) guide
2. Clone this repository to your computer
3. Open `01_DOCUMENTATION/index.html` in your browser to access all course materials
4. In your workshop folder, copy the `_TEMPLATE` folder inside `03_PROJECTS/` and rename it with your name

The repository is public so you can experience the collaborative workflow of GitHub and version control — tools that are fundamental to font development.
